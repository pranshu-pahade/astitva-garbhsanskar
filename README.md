# Astitva Garbhsanskar — Live Online Prenatal Wellness

A complete, production-ready web application for **Astitva Garbhsanskar**, a live online prenatal wellness program founded by Prajakta Dhamane & Minal Purkar.

## Features & Stack
- Next.js 15 App Router + React 19
- Supabase Integration (Reviews & Enquiries)
- Real-time English & Devanagari Marathi Translation Switcher
- WebP Image Optimization
- Mobile-First Responsive Design
- Modern WCAG AAA Accessibility & Dynamic OpenGraph Metadata
